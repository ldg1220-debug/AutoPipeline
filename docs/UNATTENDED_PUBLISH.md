# 자동 발행 안내 (동근님용)

1. **등록**: 프로젝트 폴더에서 `1` → 메뉴 마지막의 "자동 발행 스케줄 등록" 선택(또는 `scripts\install-schedule.cmd` 실행). 매일 10:20·19:40(PC 시간=한국 시간 기준)에 자동 발행되며, 로그온 상태에서만 돌고 절전이면 깨웁니다. 해제는 "자동 발행 스케줄 해제".
2. **로그 위치**: `logs\scheduled-날짜-시각.log` (실행마다 1개). 로그인 만료 기록은 `logs\login-required.log`. 하루 최대 2편·한 번에 1편이고, 내용 검사를 못 넘으면 그날은 올리지 않고 끝납니다.
3. **로그인 만료 시**: 로그에 "로그인 필요"가 보이면 `1` → 메뉴 1번(블로그 로그인) 실행 후 로그인하세요. 그 전까지는 발행하지 않습니다.
