# 자동 발행 안내 (동근님용)

> **로그인은 최초 1회 + 만료 알림이 올 때만 하면 됩니다.** 그 외에는 아무것도 누르지 않아도 됩니다.

1. **등록**: 프로젝트 폴더에서 `1` → 메뉴 마지막의 "자동 발행 스케줄 등록" 선택(또는 `scripts\install-schedule.cmd` 실행). 매일 09:20·17:20(PC 시간=한국 시간 기준)에 자동 발행되며, 로그온 상태에서만 돌고 절전이면 깨웁니다. 해제는 "자동 발행 스케줄 해제". (이전 10:20·19:40 작업이 있으면 등록할 때 자동으로 지웁니다.)
2. **로그 위치**: `logs\scheduled-날짜-시각.log` (실행마다 1개). 로그인 만료 기록은 `logs\login-required.log`. 하루 최대 2편·한 번에 1편이고, 내용 검사를 못 넘으면 그날은 올리지 않고 끝납니다.
3. **로그인 (최초 1회)**: `1` → 메뉴 1번(블로그 로그인) → 3번(크롬 창) 선택 → 카카오 로그인 화면에서 **"로그인 상태 유지"를 체크**하고 로그인. 로그인 정보는 `data\browser_profile` 폴더(전용 브라우저 프로필)에 남고, 예약 실행마다 같은 프로필로 접속해 세션을 연장합니다. 비밀번호는 어디에도 저장하지 않습니다.
4. **로그인 만료 시**: 텔레그램에 "티스토리 로그인 필요" 알림이 **만료당 1회** 옵니다(텔레그램 미설정이면 `logs\login-required.log` 에만 기록). 알림이 오면 3번과 같은 방법으로 다시 로그인하세요. 그 전까지는 발행하지 않으며 글 작성 비용도 쓰지 않습니다.
