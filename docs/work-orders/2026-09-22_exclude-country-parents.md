## 2. ★★★ 국가 단위는 코스가 성립하지 않습니다

`region=일본&days=2` 의 실제 응답입니다.

```
4곳 · 총 72.6km
  1일차  메이지 신궁(도쿄) → 우에노 아메요코 상점가(도쿄)     16.1km
  2일차  니시키 시장(교토) → 하루카스 300(오사카)            56.5km
```

**우에노(도쿄) → 니시키 시장(교토) 약 370km 가 총합에 없습니다.**

`totalDistanceKm` 는 **일자 안의 이동만** 더합니다. 같은 도시 코스에서는 맞는 설계지만,
도시가 바뀌면 **"일본 2박3일, 총 72.6km"** 라는 명백히 틀린 글이 나갑니다.

독일도 같습니다.

```
8곳 · 총 125.5km
  1일차  노이슈반슈타인 성(퓌센) → 호프브로이하우스(뮌헨)   118.2km
  2일차  포츠다머 플라츠(베를린) → … → 알렉산더 광장         7.2km
          ↑ 뮌헨 → 베를린 약 585km 가 빠져 있습니다
```

**"독일 2박3일 총 125.5km" 는 사실이 아닙니다.**

## 3. ★★★ 국내 광역 권역도 같은 문제 + 오매칭

```
충청  11곳 ·  388km        ← 일자 안 합계가 388km. 2박3일에 불가능
경상   9곳 · 284.9km       ← 대구 + 진영 혼재
전라   5곳 · 평점 전무 · "쿠팡 전라광주2,5센터 카페" · "전라맛집" · "남악저수지"
```

**전라는 다섯 중 셋이 지역명 문자열 검색 결과입니다.** 발리 → 울산 사태와 같은 계열입니다.


## 5. ★★ C-2 계약이 이걸 못 막습니다

> "이미 attachTripData의 C-2 계약(스팟 3개 미만이면 스킵)이 발행 시점에 같은 역할을 하므로"

```
일본  4곳   >  3곳  →  통과
전라  5곳   >  3곳  →  통과
태국  7곳   >  3곳  →  통과
```

**전부 통과합니다.** 기준이 느슨합니다.

```
C-2 를 이렇게 올려주세요
  · 스팟 6곳 미만                      →  스킵
  · 평점 없는 스팟이 절반 이상          →  스킵
  · 장소명에 region 문자열이 그대로 포함  →  그 스팟 제외 ("전라맛집")
  · 일자 간 도시가 바뀜 (좌표 100km 초과) →  스킵 또는 제목에 일수 재조정
```

**마지막 항목이 국가 단위를 근본적으로 막습니다.**

## 6. ★ 총거리 표기도 정확히

`totalDistanceKm` 는 **일자 내 합계**입니다. 글에 쓸 때 그대로 "총 이동"이라고 하면 오해입니다.

```
❌  "총 이동 72.6km"
✅  "하루 평균 이동 36km (1일차 16.1km · 2일차 56.5km)"
```

**같은 도시 코스에서는 차이가 없지만, 표기를 바꿔두면 위 같은 사고가 글로 안 나갑니다.**
