## 2. ★★★ 고칠 곳 — 제목 생성기와 리드 문장 생성기가 따로입니다

```
티스토리 제목    →  새 로테이션 적용됨       ✅
본문 H1 / 리드   →  옛 템플릿 그대로 남음    ✗
```

**같은 함수를 쓰게 하세요.**

```
생성한 제목을 한 번만 만들고, 그 값을
  · 티스토리 제목
  · 본문 최상단 H1
  · og / 메타 설명
에 모두 재사용
```

지금은 본문 리드가 `{키워드}, 대중교통으로 즐기는 {수식어}` 라는 **별도의 고정 문자열**을 씁니다.
그 문자열을 지우고 제목 값을 넣으면 끝납니다.

### 본문 첫 줄에 제목을 또 쓸 필요가 있습니까

티스토리는 제목을 이미 h1으로 렌더합니다. **본문 맨 위 제목은 중복입니다.**
없애면 요약에 본문 첫 문단이 잡혀 목록이 훨씬 읽기 좋아집니다.


### ★ 안전장치 — 이건 되돌리기 어렵습니다

```
· --dry-run 이 기본값. --apply 를 줘야만 실제 수정
```

**URL이 바뀌면 색인이 전부 날아갑니다.** 제목만 바꾸고 주소는 유지하세요.


미색인이 더 많은 상태라 **제목을 바꾸는 게 손해보다 이득이 큽니다.**
