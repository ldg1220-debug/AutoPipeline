## 1. ★★★ 인포카드 이미지가 빈칸입니다

```
<img src="data:image/jpeg;base64,..." alt="세부 5박7일 핵심 지표">   → 공개 페이지에서 src 비어 있음
```

티스토리가 HTML 모드로 붙인 **data: URI 이미지를 제거**합니다. 자동 발행 경로는 업로드를 거치지만, `html/{slug}.html` 수동 교체본은 그대로 깨집니다.

```
HTML export 에서
  인포카드 · 썸네일 등 로컬 이미지는 data: 로 넣지 않음
  → 트레쥴 blob 처럼 외부 URL 이 있으면 그 URL
  → 없으면 해당 <div class="info-card-wrap"> 블록을 빼고, 파일 옆에 이미지 파일을 같이 저장 + 로그 "수동 업로드 필요: assets/…/info_card.jpg"
```
