## 1. 새 메인 템플릿 (코스 글 전용)

```
제목   {지역} {N박M일} 여행 코스 | {대표1}·{대표2} 일차별 동선 + 꿀팁         (20~32자 규칙 유지)

[도입] 2~3문장
  - 첫 문장: "{지역} {N박M일}은 1일차 {테마1} → 2일차 {테마2} → 3일차 {테마3} 순서로 돌면 이동이 가장 적습니다."
  - 누구에게 맞는지 1문장 (코스 구성에서 도출: 도보 위주/테마파크 포함/야경 포함 등)

[목차]  일차별 H2 링크 + FAQ

H2  {지역} {N박M일} 전체 동선 한눈에 보기
    표: 일차 | 테마 | 핵심 장소(2~3) | 이동 수단 | 하루 이동 합계
    코스 지도 (트레쥴 course-map)
    "장소 정보 제공: Google Maps" (1곳)

H2  1일차 — {테마} (예: 난바·도톤보리 핵심 탐방)
    한 줄 소개 (그날의 성격 · 동선 방향)
    H3  {장소명}  ({종류} · 머무는 시간 제안)
        설명 2~4문장  ← §2 근거 문서에서만 (없으면 §2-④ 규칙)
        사진 1장 (§3, 있을 때만, 출처 캡션)
        📌 팁 1줄 (§2-③)
        → 다음 장소까지 {수단} {분}  (이동 정보는 여기 한 곳)
    … (그날 장소 반복)
    일자 동선 지도
    🔁 일정 조율 팁 1~2줄 (코스 데이터로 쓸 수 있는 것만: 종일시설 날 · 야간형 위치 · 가장 긴 구간)

H2  2일차 — …   (반복)

H2  떠나기 전 체크리스트
    교통·준비물 3~5줄 (위키보야주 근거 + 쿠팡 준비물 링크 자연스럽게 1~2개)

H2  {지역} {N박M일} 자주 묻는 질문
    FAQ 3개 — 코스 데이터·근거 문서로 답할 수 있는 질문만
    (예: "하루에 몇 곳을 도나요?" "걸어서 다닐 수 있나요?" "{대표명소}는 몇 일차에 가나요?")

H2  마무리
    2문장 + 트레쥴 CTA ("이 코스를 지도에서 일자별로 보고 내 일정으로 저장 · 장소를 누르면 사진·평점")

출처   위키백과·위키보야주 문서 링크 · 사진 출처(Wikimedia Commons) · 장소 정보 제공: Google Maps
```

일자 표(순서·장소·종류·다음 이동)는 위 H3 구조가 대신하므로 **삭제**. 이동 정보는 H3 끝 한 줄 + 전체 요약표 합계, 두 곳만.

## 2. 장소 설명의 근거 (지어내기 금지)

```
① 근거 문서 수집 (무료 · 약관 OK)
   한국어 위키백과 REST: https://ko.wikipedia.org/api/rest_v1/page/summary/{제목}
   없으면 영어 위키백과 → 한국어로 요약
   위키보야주(ko/en): 지역 문서의 "보기/하기/이동" 섹션 (지역 단위 팁)
   장소명 → 문서 매칭: 이름·좌표(1km 이내, 위키 좌표가 있으면) 둘 다 맞을 때만. 애매하면 설명 없이
   캐시: output/cache/wiki/{lang}/{title}.json (30일)
② LLM 재작성 (gpt-4o-mini 로 충분)
   입력 = 근거 문서 발췌 + 코스 데이터(일차·순서·종류·다음 이동) 만
   지시: "근거에 없는 사실(연도·수치·가격·영업시간·순위·'최고/유명')은 쓰지 말 것. 2~4문장. 존댓말. 이 코스에서 이 장소를 들르는 이유 1문장 포함"
③ 팁 문장: 근거 문서(위키보야주) 또는 코스 데이터에서 나온 것만
   데이터 기반 예: 야간형 → "저녁에 들르도록 그날 마지막에 배치했습니다" · 종일시설 → "이날은 이곳만 넣었습니다"
④ 근거 없는 장소(식당·카페 대부분): 설명 1문장만 — 코스상 역할로
   예: "{직전 장소}에서 도보 6분 거리라 점심 장소로 넣었습니다." (이름·종류·위치·순서만 사용)
⑤ 사실 검증 패스: 생성 설명을 문장 단위로 근거와 대조 (gpt-4o-mini, 근거에 없는 고유명사·숫자 있으면 문장 삭제)
   삭제 로그 [factcheck] removed= reason=
⑥ 게이트: 근거 있는 설명이 붙은 장소가 3곳 미만이면 글쓰기 스킵 (사유 "장소 설명 근거 부족")
```

## 3. 사진 (선택 · 무료 라이선스만)

```
위키백과 문서의 대표 이미지(pageimage) → Wikimedia Commons 라이선스 확인
허용: CC0 · Public domain · CC BY · CC BY-SA (작성자·라이선스 캡션 필수)  그 외 제외
장소당 최대 1장, 글 전체 최대 5장 · 이미지 URL 은 Commons 원본(티스토리 업로드는 기존 이미지 경로 사용)
없으면 생략 (AI 생성 이미지로 장소를 흉내 내지 말 것)
```

## 4. 기타

```
- QA 기준 갱신: "섹션당 수치 2개" 규칙은 코스 글에선 제외 → 대신 "H3 장소 중 근거 설명 ≥ 3" · "출처 블록 존재" · "★/리뷰 숫자 없음"
- 분량: 최소 2,000자 (설명이 붙으면 자연히 넘음)
- 비용 상한: 글 1편당 LLM 호출 ≤ 15회 (설명 생성 + 검증)
- THUMBNAIL_SOURCE 기본값 map (gpt-image-1 접근 불가 확인됨 — 288 로그)
- 기존 COURSE_LLM_BODY=off 는 "자유 생성 본문 금지" 의미로 유지 — 이번 설명 생성은 근거 제한 경로로 별도 플래그 COURSE_GROUNDED_DESC=on
```
