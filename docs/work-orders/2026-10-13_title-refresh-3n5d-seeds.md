## 2. 제목 규칙

```
① 키워드는 검색형 그대로, 띄어쓰기 없이: "오사카 2박3일" · "세부 3박5일" · "도쿄 3박4일"
② 제목에서 km 제거 (총 km 는 메타 설명·본문으로). "곳 수" 는 템플릿 일부에서만
③ "코스" 중복 제거 — 키워드에 이미 "코스" 가 있으면 템플릿의 "코스" 생략
④ 길이 20~32자 (네이버·구글 목록에서 잘리지 않게)
⑤ 템플릿 풀 — 글 slug 해시로 고르고, 직전 5편과 같은 템플릿은 피함
   A  "{키워드} 코스 | {대표1}·{대표2} 하루별 동선"
   B  "{키워드} 여행 코스, {대표1}부터 {대표2}까지 일정표"      ← 실제 방문 순서일 때만(첫날 첫 대표 → 마지막 날 대표)
   C  "{키워드} 일정 짜기 — {대표1}·{대표2} 들르는 {N}곳"
   D  "{키워드} 코스 정리 · 이동시간까지 본 {N}곳"
   E  "{대표1}·{대표2} 넣은 {키워드} 코스"                         ← 키워드 뒤쪽 배치 1종만
⑥ 금지: 완벽 · 최고 · 필수 · 꿀팁 · 총정리 · 이모지 · 연속 기호("— |")
⑦ 대표1·2 = 리뷰 수 상위 명소(식당·스파·숙소 제외), 이름 8자 넘으면 1개만
```

```
세부 3박5일 일정 짜기 — 마젤란의 십자가·레아신전 들르는 14곳
상하이 3박4일 코스 정리 · 이동시간까지 본 15곳
```
