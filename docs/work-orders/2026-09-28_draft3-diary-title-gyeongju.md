## 3. ★★★ 제목이 사실과 다릅니다

```

실제 평점  4.9 · 4.9 · 4.8 · 4.6 · 4.6 · 4.5 · 4.4 · 4.3 · 4.2 · (해변 없음)

"최고 평점 N"  → 최댓값을 쓸 때는 이 표현
```
