## 2. 전체 구조 — 5블록 고정

```
[A] 도입 1~2문장      질문에 대한 결론 + 왜 그렇게 나누는지
[B] 일차별 코스        장소 · 평점(리뷰수) · 다음까지 이동시간
[C] 주의/팁 1~2문장    리뷰 근거가 있을 때만. 없으면 빈칸
[D] 개인 코멘트 자리    ← LLM이 쓰지 않음. 사람이 채움
[E] 링크 0~1줄        조건 충족 시에만
```

**순서를 바꾸지 마세요.** 지식iN 독자는 첫 두 줄만 보고 계속 읽을지 정합니다.

## 3. 블록별 규칙

### [A] 도입 — 1~2문장

```
✅  "오사카 처음이시면 성·전망대 쪽과 항만 쪽을 하루씩 나누는 게 동선상 편합니다."
✅  "부산 1박2일이면 원도심과 해운대를 나누는 게 낫습니다. 두 권역이 지하철로 30분 넘게 걸려서요."

❌  "안녕하세요! 여행 좋아하는 사람입니다~"      ← 인사말 금지
❌  "오사카는 정말 매력적인 도시죠!"             ← 감상 금지
❌  "질문 주신 오사카 2박3일 코스 답변드립니다"   ← 질문 되풀이 금지
```

**첫 문장에 반드시 "왜 이렇게 나누는가"가 들어가야 합니다.**
장소 나열은 누구나 하지만, 이유는 데이터가 있어야 씁니다.

### [B] 코스 — 형식 고정

```
**1일차 (도심, 총 15km)**
오사카 성 ★4.4 (리뷰 99,648)
→ 59분 · 오니기리 고리짱 ★4.9 (리뷰 13,506)
→ 25분 · 우메다 스카이빌딩 ★4.4 (리뷰 43,408)
```

| 규칙 | 값 |
|---|---|
| 일차 제목 | `**N일차 (권역, 총 N km)**` — 권역은 지명 한 단어 |
| 장소 줄 | `이름 ★평점 (리뷰 N)` |
| 이동 | `→ N분 · ` 을 다음 장소 앞에 |
| 평점 없음 | **그 장소를 아예 빼기** |
| 리뷰수 | 천 단위 쉼표 |
| 하루 장소 수 | 3~6곳. 넘으면 앞에서 자르기 |

**이모지·불릿(•, -)을 쓰지 마세요.** 지식iN 에디터에서 깨집니다.

### [C] 팁 — 리뷰 근거가 있을 때만

```
✅  "규카츠 모토무라는 웨이팅이 길어서 오픈 시간에 맞춰 가시는 걸 권합니다."
    (근거: "웨이팅 40분"(★4, 2개월 전), "오픈런 추천"(★5, 1달 전))

❌  "현지 분위기를 느끼기 좋습니다"        ← 근거 없음, 아무 말
❌  "미리 예약하시면 좋아요"               ← 리뷰에 없으면 추측
```

**리뷰 2건 이상에서 같은 이야기가 나올 때만 씁니다.**
1건뿐이면 개인 경험일 수 있습니다. 근거가 없으면 **이 블록을 통째로 비우세요.**

### [D] 개인 코멘트 — LLM이 쓰지 않습니다

```markdown
(여기에 직접 한 줄 — 안 쓰면 그냥 지우고 올리세요)
```

이 문구를 그대로 출력하세요. **LLM이 채우면 안 됩니다.**
동근님이 아는 게 없으면 지우고 올리면 되고, 있으면 그게 답변의 값어치가 됩니다.

### [E] 링크 — 조건부 1줄

```
✅  "지도로 보시려면: {URL}"
✅  (링크 없음)

❌  "자세한 정보는 여기서 확인하세요! → {URL}"
❌  "제가 쓰는 앱인데 편해요 {URL}"
❌  링크 2개 이상
```

`history.json` 조건을 통과하지 못하면 **이 블록을 출력하지 마세요.**

## 4. ★ 길이

```
전체 400~700자
[A] 40~120자
[B] 코스 (길이 제한 없음, 장소 수로 제어)
[C] 0~120자
```

**1,000자를 넘기지 마세요.** 지식iN에서 긴 답변은 스크롤로 넘어갑니다.

## 5. ★★ 매번 달라야 합니다

같은 지역 질문이 반복됩니다. **도입 문장이 같으면 네이버가 잡아냅니다.**

```
프롬프트에 함께 넣을 것:
  output/kin/ 의 같은 지역 기존 원고에서 [A] 블록만 추출해 나열
  "아래 문장들과 겹치는 표현을 쓰지 말 것"
```

도입부를 다르게 쓰는 축 세 가지를 프롬프트에 예시로 주세요.

```
· 동선 기준   "○○과 △△를 하루씩 나누는 게 이동상 편합니다"
· 시간 기준   "2박3일이면 첫날은 이동이 있으니 가볍게 잡는 게 낫습니다"
· 조건 기준   "렌트 안 하신다면 지하철로 닿는 곳 위주가 편합니다"
```

**질문에 조건이 있으면 조건 기준을 우선**하세요. 맞춤 답변으로 보입니다.
