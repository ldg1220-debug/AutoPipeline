## 3. ★★★ 방향 전환 — 같은 엔진을 트레쥴 쪽에 쓰세요

지금 파이프라인이 하는 일입니다.

```
course-brief  →  LLM 으로 글 생성  →  티스토리 발행  →  CTA 로 트레쥴 유입
                                          ↑ 여기서 막힘
```

바꿀 방향입니다.

```
course-brief  →  LLM 으로 설명문 생성  →  트레쥴 코스 페이지에 공급  →  직접 검색 유입
```

**트레쥴 코스 페이지는 블로그 글보다 SEO 품질이 높습니다.**
실제 장소명·평점·리뷰수·이동시간·지도가 들어가고, 얇은 자동 생성 글이 아닙니다.
그리고 **도착지가 곧 서비스라 중간 이탈이 없습니다.**

### AutoPipeline 이 할 일

```
1. 지역 × 일수 조합 목록을 관리         (어디를 먼저 만들지)
2. course-brief 호출 + 품질 판정        (스팟 5곳 미만 / 평점 없음 → 제외)
3. 장소별 설명문 생성                   (리뷰 근거, 템플릿 문장 금지)
4. 트레쥴에 공급                        (API 또는 저장소 커밋)
5. 색인 요청 + 결과 추적
```

**3번이 핵심이고, 지금 블로그에 쓰던 그 능력입니다.**
다만 블로그에서 한 실수(같은 틀 반복)를 그대로 가져오면 안 됩니다.

> 트레쥴 쪽 페이지·URL 작업은 짝 지시서에 있습니다. 이 저장소는 **내용 공급**만 맡습니다.
> 인터페이스는 두 세션이 합의해서 정하세요.

## 4. ★★★ 사람을 데려오는 건 지금 지식iN 뿐입니다

블로그는 색인이 붙는 데 오래 걸리고, 코스 페이지도 2주는 봐야 합니다.
**당장 이번 주에 사람을 데려올 수 있는 채널은 지식iN 하나입니다.**

```
네이버 검색에서 지식iN 은 블로그보다 위에 노출됩니다.
"경주 2박3일 코스 추천" 같은 질문은 매일 올라옵니다.
```

### 자동화 가능한 범위

```
✅  질문 수집 · 선별 · 답변 초안 생성 · 근거 수집
❌  자동 게시  —  네이버 약관 위반입니다. 하지 마세요.
```

```
런처에서  2번 지식iN  →  초안 생성  →  동근님이 복붙
```

**하루 3건이 현실적인 목표입니다.** 채택된 답변은 계속 노출됩니다.

### 답변에 트레쥴 링크를 넣는 방법

```
❌  답변마다 링크  →  광고로 신고당합니다
✅  실제 코스 내용을 답변에 다 적고, 끝에 한 줄
    "동선 지도로 보시려면: (링크)"
✅  3~4건에 1건만 링크
```

**링크 없는 답변이 채택되는 게 링크 있는 답변이 삭제되는 것보다 낫습니다.**

## 5. ★★ 진짜 자동화는 사용자가 쓰게 만드는 것입니다

자동 생성 콘텐츠는 늘 구글과 싸웁니다. **사용자가 쓴 후기는 그 싸움이 없습니다.**

```
/trip/5 는 이미 SSR 이 완벽합니다 — 색인만 안 되고 있습니다 (짝 지시서 §3)
```

선순환을 만드세요.

```
코스 페이지로 유입  →  담아가기  →  여행  →  후기 작성  →  후기가 색인  →  더 유입
                                        ↑ 여기를 자동화
```

### AutoPipeline 이 할 수 있는 것

```
· 계획 저장 후 일정이 지나면 "후기 남기기" 알림 (메일 / 앱 알림)
· 후기 작성 시 계획을 자동으로 불러와 초안 뼈대 제공
    → 사용자는 감상만 쓰면 됨
· 후기 발행 시 sitemap 갱신 + 색인 요청
```

**후기 1건이 자동 생성 글 10편보다 낫습니다.** 지금 후기가 6건뿐인 게 기회입니다.

## 6. ★ 배너를 켤 때 같이 고칠 것

```
· CTA 문구        "트레쥴에서 확인하기"  →  무엇을 확인하는지 불명확
                  "이 코스 지도로 보기"  ·  "내 일정으로 담아가기"
· 위치            글 맨 밑 하나만  →  코스 표 바로 아래에도 하나

                  ?utm_source=blog&utm_medium=cta&utm_campaign={지역}
```

**utm 없이는 배너 효과를 영원히 알 수 없습니다.**
