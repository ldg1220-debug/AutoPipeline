## 3. ★★★ 숫자는 이미 손에 있습니다 — 안 쓰고 있을 뿐입니다

트레쥴 `course-brief`가 주는 값입니다.

```
spots[]      name · category · rating · reviewCount · lat · lng
             order · day · toNextMinutes · toNextMode
dayTotals[]  day · distanceKm · spotCount
             totalDistanceKm · distanceSource
```

**평점, 리뷰 수, 구간 이동 시간, 일자별 거리가 전부 있습니다.**
그런데 글에는 "효율적으로 이동할 수 있다"만 들어갑니다.

### 이렇게 바꾸세요

**지금**

> 하노이에서의 3박 4일 동안, 시간대별로 동선을 잘 짜면 보다 효율적이고 편안한
> 여행이 가능하다. 첫날, 하노이 노이바이 국제공항에 도착하면 구시가지까지…

**바꾼 뒤**

```
### 1일차 — 공항에서 구시가지로 (이동 3.2km)

| 순서 | 장소 | 다음까지 | 평점 |
|---|---|---|---|
| 1 | 노이바이 국제공항 | 버스 70분 | — |
| 2 | 하노이 구시가지 | 도보 8분 | ★4.5 (8,210) |
| 3 | 호안끼엠 호수 | — | ★4.6 (12,400) |

**구시가지에서 호안끼엠 호수까지는 도보 8분입니다.** 이 구간은 차로 가는 것보다
걷는 편이 빠릅니다.
```

**표가 들어가면 강조할 문장이 저절로 생깁니다.** 순서가 반대입니다 —
서식을 먼저 넣는 게 아니라, **사실을 넣으면 서식이 필요해집니다.**

## 4. ★★ 섹션마다 시각 요소 하나

내용이 채워진 다음에 적용할 규칙입니다.

```
H2 섹션 하나당 최소 1개:
   표  ·  체크리스트  ·  인용 박스  ·  숫자 카드
```

```
문단은 3줄(약 120자) 넘기지 말 것       ← 지금 평균 139자
같은 형태의 문단 3개 연속 금지
섹션 끝에 한 줄 요약 (굵게) 1개
```

### 굵게는 섹션당 1~2개만

```
❌  여러 문장을 굵게  →  강조가 사라짐
✅  그 섹션에서 기억할 사실 하나만 굵게
```

**굵게 칠할 것은 숫자가 든 문장입니다.** "도보 8분", "3.2km", "★4.6" 처럼요.

## 5. ★★ 맨 위 요약 박스를 제대로

지금 "📋 한눈에 보기"는 문장 5개를 목록으로 늘어놓은 것뿐입니다.

```
📋 한눈에 보기
   · 하노이 3박4일 코스를 통해 대중교통과 도보를 활용하여…
   · 하노이에서의 3박 4일 동안, 시간대별로 동선을 잘 짜면…
```

**본문 첫 문장을 그대로 복사했습니다.** 읽을 이유가 없습니다.

```
📋 한눈에 보기
   총 이동      12.4 km  (3일)
   장소         13곳
   주요 이동    버스 · 도보
   하이라이트    호안끼엠 호수 ★4.6 · 미딘 야시장 ★4.3
```

**숫자 4줄이면 충분합니다.** 스크롤 안 해도 글의 값어치가 보입니다.

## 7. ★ 발견 — 구조화 데이터에 옛 제목이 남아 있습니다

동근님이 티스토리 제목을 고치셨는데, 본문 안 JSON-LD는 그대로입니다.

```
<script type="application/ld+json">
  "headline": "하노이 3박4일 코스, 대중교통으로 즐기는 최적 동선"
```

```
티스토리 제목    "하노이 3박4일 코스 꿀팁 동선"                    (수정됨)
JSON-LD         "하노이 3박4일 코스, 대중교통으로 즐기는 최적 동선"  (옛것)
본문 첫 줄       "하노이 3박4일 코스, 대중교통으로 즐기는 최적 동선"  (옛것)
```

**구글이 셋 중 무엇을 제목으로 볼지 모릅니다.** 신규 발행에서 세 곳이 같은 값을
쓰게 하세요 (앞 지시서 §2와 같은 작업입니다).
