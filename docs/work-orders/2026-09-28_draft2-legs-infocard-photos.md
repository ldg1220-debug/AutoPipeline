```

  (출발 스팟명) … (도착 스팟명) … (도보|대중교통|차량|차) … N분
```


**같은 글에 3.2시간과 6시간이 같이 나갑니다.** Pass 5 가 "출처 없는 수치" 로 잡았지만 가드 때문에 되돌려졌습니다.

```
info_stats 는 LLM 본문에서 뽑지 말고 trip_data 로 코드가 만드세요
  총 이동 거리  = totalDistanceKm
  이동 시간     = Σ toNextMinutes   (라벨도 "소요 시간" 이 아니라 "이동 시간")
  장소 수       = spots.length
  최고 평점     = max(rating) + 스팟명
```
