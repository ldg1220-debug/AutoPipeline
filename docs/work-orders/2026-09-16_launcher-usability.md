## 1. 실제로 일어난 일

```
[1/3] 방식
  1  키워드 직접 지정
  2  자동 선정 (기존 파이프라인)

  ⚠ 이해하지 못했습니다. 다시 입력해주세요.
```

**같은 입력을 세 번 하셨습니다.** 메뉴는 정상 동작했지만,
**"키워드 직접 지정"이라고 써 있으니 키워드를 치신 것**입니다. 당연한 반응입니다.

---

## 2. ★★★ 키워드를 바로 받으세요

```
[1/3] 방식
  1  키워드 직접 지정
  2  자동 선정
선택 > 경주 2박3일          ← 이걸 그대로 받아야 합니다
```

```
입력이 "1" 또는 "2"  →  기존 분기
그 외 텍스트          →  키워드 직접 지정으로 보고, 그 텍스트를 키워드로 사용
                        (지역·일수를 파싱해 다음 단계를 건너뜀)
빈 입력              →  기본값(1)
```

**메뉴는 안내일 뿐, 사용자가 답을 이미 알고 있으면 바로 받는 게 맞습니다.**

### 파싱 결과는 확인받으세요

```
> 경주 2박3일

  지역: 경주    일수: 2박3일(3일)
  맞습니까? (Y/n) >
```

틀리게 읽었을 때 사용자가 바로잡을 자리가 필요합니다.

## 3. ★★ 오류 메시지가 방법을 알려줘야 합니다

```
지금:  ⚠ 이해하지 못했습니다. 다시 입력해주세요.
변경:  ⚠ 1 또는 2를 입력하거나, 키워드를 바로 입력하세요. (예: 경주 2박3일)
       ⚠ 취소하려면 0
```

**세 번 연속 같은 오류가 나면 도움말을 자동으로 펼치세요.**
사용자가 같은 걸 세 번 쳤다는 건 메시지가 안 통했다는 뜻입니다.

---

## 4. ★★ 시작 경고가 과합니다

```
[config] WARNING: "OPENAI_API_KEY" is not set.
[config] WARNING: "YOUTUBE_CLIENT_ID" is not set.
[config] WARNING: "YOUTUBE_CLIENT_SECRET" is not set.
[config] WARNING: "YOUTUBE_REFRESH_TOKEN" is not set.
[config] WARNING: "TISTORY_ACCESS_TOKEN" is not set.
[config] WARNING: "TISTORY_BLOG_NAME" is not set.
```

**여섯 줄 중 넷은 유튜브입니다.** 영상 파이프라인은 6월에 중단됐습니다.
런처를 켤 때마다 이게 뜨면 "뭔가 고장났나" 싶습니다.

```
런처 실행 시에는 config 경고를 억제하고,
필요한 것만 4번 "설정 확인"에서 보여주세요.
```

```
[여행 채널에 필요한 것]
  LLM            ✅ Grok
  트레쥴 API      ✅
  티스토리 세션    ✅ (쿠키 로그인)
  Pexels         ✅

[안 쓰는 것]  유튜브 · TTS · 틱톡  — 영상 파이프라인 중단(2026-06)
```

### ⚠️ 확인 필요 — 지식iN 초안이 어떤 LLM을 쓰는가

`OPENAI_API_KEY`가 비어 있는데 블로그는 정상 발행되고 있습니다(오늘 09:47 방콕).
**Grok 등 다른 제공자로 돌고 있다는 뜻입니다.**

```
write-kin-answer.js 가 OpenAI 전용이면  →  지금 상태에서 실패합니다
```

**블로그와 같은 제공자를 쓰도록 맞추거나, 없으면 명확히 안내**하세요.

## 5. ★ 단계 표시가 실제 단계 수와 다릅니다

```
[1/3] 방식  →  다음이 [2/3] 지역?  [2/4]?
```

키워드를 직접 주면 단계가 줄어듭니다. **고정된 `/3`은 틀립니다.**

```
[방식]  [지역]  [일수]  [확인]      ← 진행한 것만 표시
```

또는 단계 번호를 아예 빼세요. 4단계짜리 대화에 번호는 없어도 됩니다.
