## 1. 왜 — 지금 싣는 이동 수치가 직선거리입니다

트레쥴 `course-brief`의 `totalDistanceKm`와 `toNextMinutes`를 검증했습니다.

```
경주 d1   API 3.2km   직선 합 3.19km    차이 0.01
통영 d1   API 27.7km  직선 합 27.68km   차이 0.02
오사카 d3 API 13.6km  직선 합 13.64km   차이 -0.04
```

**도로 거리가 아니라 직선거리입니다.** 시간도 `직선 ÷ 고정속도`입니다
(walk 4.8km/h, car 24~25km/h로 딱 떨어집니다).

`maeilg.com`에 이렇게 나갔습니다.

```
총 이동 27km · 6곳 · 약 1.2시간
이동수단: 차량, 도보 기준
```

**첫 구간이 `사량도 → 중앙활어시장`인데 사량도는 섬입니다.**
배로 들어가야 하는 곳을 "차량 51분"으로 적었습니다.

트레쥴 쪽에 실제 경로 API 연동을 지시서로 보냈습니다.
**그게 끝날 때까지, 발행되는 글마다 틀린 수치가 쌓입니다.**

## 2. ★★ 임시 조치 — 표기만 정직하게

수치를 고치지 마세요. 트레쥴이 곧 진짜 값을 줍니다.
**지금은 그 값이 무엇인지만 정확히 적으면 됩니다.**

### TL;DR 박스

```
현재:  총 이동 27km · 6곳 · 약 1.2시간
변경:  직선거리 기준 약 27km · 6곳
```

**소요시간은 아예 빼세요.** 직선거리를 고정 속도로 나눈 값이라
실제와 가장 크게 어긋나는 항목입니다. 거리는 하한선이라도 되지만
시간은 근거가 없습니다.

### 이동수단 줄

```
현재:  이동수단: 차량, 도보 기준
변경:  (삭제)
```

경로를 조회한 게 아니라 거리로 추정한 값이라, 그 구간을 실제로
차로 갈 수 있는지 알 수 없습니다.

### 본문에 한 줄

거리를 언급하는 섹션 아래에 넣으세요.

```
※ 거리는 장소 간 직선거리 기준입니다. 실제 이동 거리와 시간은 경로에 따라 더 깁니다.
```
