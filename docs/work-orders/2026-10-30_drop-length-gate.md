# 작업 지시서 — 코스 글 글자 수 기준 폐지 → "내용 게이트"로

작성: 2026-10-30 · 대상: **AutoPipeline** (`ldg1220-debug/AutoPipeline`)
근거: 동근님 질문("왜 2,500자·3,000자로 제한하나") — Cowork 판단: 글자 수는 얇은 글을 막으려던 임시 대리 지표. Google 은 길이를 순위 요소로 쓰지 않고, 길이를 맞추려다 반복·군더더기가 생김.

## 0. 먼저 — 이 지시서를 저장소에 보관

1. `docs/work-orders/2026-10-30_drop-length-gate.md` 로 저장
2. **완료된** 지시서 중 오래된 것부터 지워 10개 유지 (미완료 건은 남길 것)
3. 본 작업과 **같은 PR에** 포함 (main 직접 반영이면 같은 커밋)

## 1. 할 것

```
① 코스 글(근거 경로 COURSE_GROUNDED_DESC=on) 의 글자 수 반려 삭제 — 2,500자 · 2,000자 · 1,500자 모두
   글자 수는 로그·리포트에 기록만 (word_count)
② 내용 게이트 (하나라도 못 넘으면 스킵 — 지어서 채우지 말 것)
   - 근거 설명(위키·위키보야주) 붙은 명소 ≥ 3
   - Commons 사진 ≥ 2
   - 시간표 · FAQ 5 가 코스 데이터로 채워짐
   - 지어낸 수치 패턴 0 · ★/리뷰 숫자 0 (기존 유지)
③ 분량 보강용으로 넣었던 반복성 문장(동선 요약 중복 등)이 남아 있으면 제거
④ 일반(비코스) 글은 이번 범위 밖 — 기존 기준 유지
```
