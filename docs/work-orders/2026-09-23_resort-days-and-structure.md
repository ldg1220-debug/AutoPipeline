## 2. ★★★ 휴양형 글은 구성이 달라야 합니다

도시형 틀(시간대별 동선 · 장소별 상세 · 이동 방법)을 휴양지에 쓰면 이렇게 됩니다.

```
"1일차 09:00 ○○ → 10:30 ○○ → 12:00 ○○ …"   ← 리조트에서 쉬러 간 사람에게 맞지 않음
```

휴양형 섹션 예시입니다.

```
① 숙소는 어디에 — 권역별 차이 (막탄 vs 세부시티 / 우붓 vs 스미냑)

③ 꼭 할 액티비티 — 호핑·스노클링·투어 (코스 데이터의 평점·리뷰수)
④ 쉬는 날 보내기 — 스파·카페·해변
⑤ 맛집 · 야시장
```

**"휴식" 을 빈칸으로 보지 말고 섹션으로 쓰세요.** 그게 이 여행의 본질입니다.
