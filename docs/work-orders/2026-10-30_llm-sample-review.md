   규칙: 출처 문서가 없는 스팟은 설명 문장 0 (종류·머무는 시간·다음 이동만).

## 2. 문장 품질

```
④ 모든 장소가 같은 틀: "X는 ○○에 위치한 Y입니다. 이곳에서는 ~할 수 있습니다." (경주 11회)
   → 첫 문장은 원문에서 그 장소만의 사실(연대·특징·볼거리 1개), 둘째 문장은 원문에 있으면 실용 정보(관람 포인트·시간대).
     "위치한 ~입니다", "이곳에서는 ~할 수 있습니다" 각각 글당 최대 2회.
⑤ 군더더기 삭제: "1일차 첫 일정으로 넣었습니다" · "○○ 다음 순서로 넣었습니다" · "○○일차 마지막 일정으로 넣었습니다" (순서는 이미 표·→다음 으로 보임)
⑥ 오사카 성 "아즈치모모야마 시대부터 에도 시대의 성입니다" 처럼 문법 깨진 요약 → LLM 요약 후 문장 검사(조사 연결 오류) 또는 원문 첫 문장 그대로 사용
⑦ 이름 정리: "대한불교조계종 석굴암" → "석굴암" (종단·교구 접두어 제거 — 표·H3·제목·목차 모두)
⑧ 식사 위치: "→ 다음: 우렁각시 차량 5분" 다음 H3 가 추억의달동네라 끊겨 보임
   → 식사·카페는 순서 자리에 한 줄로: "🍽 점심 — 우렁각시 (도보 2분)" , 일차 끝 "먹고 쉬기" 목록은 삭제(중복)
```

## 3. 데이터·표기 정리

```
⑨ 머무는 시간: 경주월드(테마파크) 60분 → 테마파크는 최소 180분(종일 아님일 때). 
   성동시장 "추천 시간대 아침(위키 문서 기준)" 인데 오후 배치 → 배치와 어긋나면 이 표기 생략
⑩ 야경: "시간표에서 이 일정 시각을 뒤로 옮기면" → 시각이 없어졌으니 "해 질 무렵에 맞춰 가면" 으로.
   야경 후보에 전망대뿐 아니라 원문에 야경/야간 조명이 있는 곳(동궁과 월지·월정교·도톤보리)도 포함
⑪ "하루 평균 3.0곳" → "하루 3곳 안팎" (소수점 .0 제거)
⑫ "차량 기준 16분" / "차량 16분" 표기 통일 → "차량 16분"
⑬ 오사카: 쿠팡 고지가 상단·하단 2회 → 상단 1회만
⑭ 경주 has_affiliate:false 인데 Klook 링크(경주타워) 있음 → 플래그 갱신. JSON-LD headline 이 실제 제목과 다름 → 제목과 동일하게
```
