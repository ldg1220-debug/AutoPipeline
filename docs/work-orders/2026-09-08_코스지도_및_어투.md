## 2. ★★★ 코스 지도 이미지를 안 쓰고 있습니다

`course-brief` 응답에 `imageUrl`이 들어옵니다. 지금 이렇게 생겼습니다.

```
  1280×1000 · 번호 마커(①②③④) + 스팟 사이 동선 라인
```

**실물을 확인했습니다. 아주 잘 나옵니다.**

그런데 `/248`의 본문 이미지는 이렇습니다.

```
Pexels 스톡 5장
지도 0장
```

```
Photo by Jhany Blue on Pexels      ← 속초와 무관
Photo by 대정 김 on Pexels          ← 통영과 무관
Photo by SOO CHUL PARK on Pexels   ← 제주와 무관
```

**여행 글에 그 장소가 아닌 사진이 들어가는 건 신뢰를 깎습니다.**
반면 코스 지도는 **그 글에만 있는 자산**이고, 그 자체가 트레쥴 결과물이라
콘텐츠와 홍보가 동시에 됩니다.

### 수정

```
tradule_source.js  : brief.imageUrl 을 trip_data 에 그대로 담을 것
monetizer.js       : TL;DR 박스 바로 아래에 지도 1장 삽입

  <img src="{trip_data.imageUrl}" alt="{지역} {일수} 코스 지도" loading="lazy">
  <p class="photo-credit">코스 지도 · 트레쥴</p>
```

**Pexels 사진을 전부 없애자는 건 아닙니다.** 지도를 맨 위 대표 이미지로 두고,
섹션 사진은 그대로 두시면 됩니다. 다만 **`imageUrl`이 null이면 지도는 생략**하세요.

> 참고: 지금 트레쥴 쪽에 "블로그 CTA를 눌러도 계획이 비어 있는" 버그가 있어
> 별도 지시서를 보냈습니다. 지도 이미지 자체는 정상이라 이 작업과 무관합니다.
