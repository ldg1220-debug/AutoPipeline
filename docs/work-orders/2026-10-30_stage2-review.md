## 2. 고칠 것

```
① 시간표가 14:40·15:50 에 끝남 → 실제 여행처럼 보이지 않음
   정확한 분 단위 대신 "시간대 블록" 으로: 오전 / 점심 / 오후 / 해 질 녘 / 저녁
   규칙: 식사 스팟은 점심(첫 식사)·저녁(두 번째 식사) 블록에 고정, 전망대·야간형이 그날 마지막이면 "해 질 녘~저녁",
         나머지는 순서대로 오전→오후에 배분. 블록 옆에 "권장" 표기 유지
   (머무는 시간 표는 장소 H3 의 "머무는 시간"으로 충분)
② "코스의 권역 — 왜 이렇게 나눴나" 섹션이 기계적("장소 5곳을 한 날에 묶었습니다. 이동 수단은 …섞여 있습니다") → 섹션 삭제
   대신 각 일차 첫 문단에 1~2문장: 그날 권역의 성격(위키/위키보야주 근거 있으면) + "장소끼리 도보 N분 안"(데이터)
③ 일차 제목의 행동이 "둘러보기" 로 일반적 → 그날 카테고리 구성에서: 시장 있으면 "시장 먹거리", 전망대 마지막이면 "전망대 야경",
   사원·유적 다수면 "역사 산책", 해변이면 "해변 산책", 테마파크면 "하루 종일" — 해당 없으면 행동 생략
④ 위키 원문이 어색한 경우(구로몬 시장 "한국식 음식들을 많이 진열되는…") — LLM 재작성 경로에서 자연스럽게 되는지 실제 실행으로 확인 (아래 §3)
⑤ 2,500자 게이트는 유지. 못 넘는 코스는 스킵 (기준 낮추지 않음)
```
