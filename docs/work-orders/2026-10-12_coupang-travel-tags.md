## 1. 링크 표 형식 확장 (`data/coupang/links.json`)

```json
{ "name": "여행용 멀티 어댑터 110V 돼지코", "url": "https://link.coupang.com/a/....",
  "keywords": ["멀티어댑터","돼지코"], "tags": ["japan","overseas"], "season": "all" }
```

- `tags` 가 있는 항목만 여행 글 후보. 기존 26개(경제·뷰티 등)는 tags 없음 → 여행 글에 안 나감
- `season`: all · summer · winter (선택)

```

링크 rel="nofollow sponsored"
```
