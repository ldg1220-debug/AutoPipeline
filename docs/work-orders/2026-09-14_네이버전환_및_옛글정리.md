## 2. ★★★ 발행 편수를 줄이고 네이버 원고로 돌리세요

```
지금:  티스토리 자동 발행 위주
변경:  티스토리 주 2~3편  +  네이버 원고 파일 생성
```

한국 여행 검색은 네이버가 압도적입니다.
**네이버 블로그 글쓰기 API는 2020년 종료**라 자동 발행이 안 되고,
그래서 지금까지 구글만 봐왔는데 — **그 회피가 채널을 결정해버렸습니다.**

### 네이버 원고 저장 (순위 6으로 지시했던 것)

```
output/blog/naver/{date}_{slug}.md

· 제목을 티스토리와 다르게          (중복 콘텐츠 회피)
· 도입부 2~3문장 변형
· 코스 지도 이미지 경로를 함께 적기   (복붙 시 첨부용)
· 평점·리뷰수 표는 그대로            ← 이게 차별점입니다
· 티스토리 링크는 넣지 말 것
· eSIM 제휴 링크도 넣지 말 것        ← 네이버는 외부 제휴링크에 엄격합니다
```

**편당 복붙 10분이면 네이버 채널이 열립니다.**

> 이미 구현돼 있으면 동작 확인만 하고 알려주세요.

## 3. ★★ 검색량 게이트를 다시 보세요

노출 38회가 말해주는 건 **게이트가 사실상 통과만 시키고 있다**는 것입니다.

```
확인할 것
· 게이트 임계값이 얼마인가
· autoMode에서 fail-closed 가 실제로 닫히고 있는가
· 통과한 키워드들의 실제 월 검색량 로그가 남는가
```

```
권장: 월 검색량 1,000 미만 키워드는 발행하지 않음
      (지금 임계값이 그보다 낮으면 올리세요)
```

**편수보다 키워드 하나의 질이 중요해졌습니다.**
주 2편이어도 검색량 있는 키워드면 지금보다 낫습니다.

## 4. ★★ 옛 경제 글 194편 — 도메인을 갉아먹고 있습니다

```
색인 미생성 216개  >  색인 생성 170개
```

**구글이 이 도메인의 절반 이상을 "색인할 가치 없음"으로 판단했습니다.**
새로 쓰는 여행 글도 그 도메인 평가를 같이 받습니다.

### 선택지

| 방법 | 장점 | 단점 |
|---|---|---|
| **삭제** | 가장 확실 | 되돌릴 수 없음 |
| `noindex` 메타 추가 | 글은 남음 | 티스토리에서 글마다 수정 필요 |
| 그대로 둠 | — | 도메인 평가가 계속 눌림 |

**삭제를 권합니다.** 경제 채널로 돌아갈 계획이 없고, 3개월간 클릭이 14회입니다.
**보존 가치가 없습니다.**

```
scripts/purge-legacy-posts.js  (신규)

· strip-coupang-links.js 와 같은 방식(로그인된 티스토리 세션)
· 대상: 카테고리가 여행이 아닌 글
· --dry 로 목록만 먼저 출력  ← 반드시 사람이 눈으로 확인
· --apply --limit 5 로 소량 먼저
· done.json 으로 재개 가능
```

**`--dry` 목록을 동근님이 확인하기 전에는 절대 삭제하지 마세요.**
지우면 복구가 안 됩니다.
