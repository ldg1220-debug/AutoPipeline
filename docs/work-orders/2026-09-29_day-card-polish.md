## 3. ★★★ 카드 밑 LLM 해설을 빼세요

카드(표 + 포인트)가 들어가니 해설이 **표를 다시 읽어주는 문장**만 남았고, 상투어 게이트가 중간을 지우면서 **주어 없는 파편**이 됐습니다.

```
3일차  "이 음식점은 ★4.8의 높은 평점을 받고 있어 음식의 질이 기대된다. 이곳은 ★4.1의 평점으로 …"
       ← 가게 이름이 지워지고 "이 음식점은 / 이곳은" 만 남음
4일차  "오전에는 House of Lechon 에서 ★4.5의 만족도를 … 마지막으로 The Pig and Palm 에서 ★4.5의 식사를 …"
       ← 가운데 Thai Royale Spa 문장이 삭제됨
5일차  "이곳은 기타 분류이며 평점은 ★4.9로 매우 높다"   ← 내부 분류명 "기타" 가 본문에 노출
2일차  "평점이 ★4.6으로 평가되어 있다 … 이 음식점 역시 ★4.6의 평점을 받았다"   ← 표 반복
```

**지금 이 해설이 글에서 가장 "AI 가 쓴 것 같은" 부분이고, 정보는 0 입니다.**

```
일자 카드 = 지도 + 부제 + 표 + 포인트 문장   (LLM 해설 없음)
```

길이가 줄어드는 건 **QA 가 표·포인트 텍스트를 글자수에 포함**하면 해결됩니다(9/28 지시서 §2③). 포함되는지 확인해주세요.

## 4. ★★ 부제에서 "기타" 를 빼세요

트레쥴 category 가 "기타/음식점/숙소" 수준이라 부제가 "음식점 1곳 · 기타 1곳" 이 됩니다.
**이름으로 분류하면 대부분 풀립니다.** 코드 규칙으로:

```
이름에  spa|스파|massage|마사지     → 스파
        beach|비치|해변|island|섬    → 해변
        park|공원|파크              → 공원
        temple|사원|사|성당|church   → 사원·성당
        market|시장                 → 시장
        fort|요새|성|궁              → 유적
        호텔|hotel|resort|리조트     → 숙소
category 음식점 → 식사 · 카페 → 카페 · 관광지 → 명소
그 외 "기타" → 부제에서 생략 (표의 종류 칸은 "—")
```

```
3일차 — 식사 · 공원 (이동 22분)
5일차 — 스파 · 식사 (이동 22분)
```
