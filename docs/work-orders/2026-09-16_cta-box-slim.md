## 1. 지금 모습

```html
<div class="cta-box">
  <h3>📌 매일 떠나는 남자</h3>
  <p>실제 평점·동선 데이터로 검증한 여행 코스를 소개합니다.</p>
  <p>이 코스를 앱에서 그대로 열어보세요 →</p>
  <a>트레쥴에서 후쿠오카 코스 보기</a>
</div>
```

```css
.cta-box {
  background: linear-gradient(135deg, #1e3a8a 0%, #3b82f6 100%);
  padding: 32px 24px;  color: #fff;  text-align: center;
  box-shadow: 0 6px 24px rgba(30,58,138,.3);
}
```

**진한 파란 덩어리가 본문 끝에 큼직하게 박힙니다.**
제목·설명·안내·버튼까지 네 줄이라 광고 배너로 읽힙니다.

---

## 2. ★★ 문제

| 항목 | 지금 | 왜 문제인가 |
|---|---|---|
| 배경 | 진한 파란 그라데이션 | 본문과 대비가 너무 커서 시선이 튐 |
| 제목 | "📌 매일 떠나는 남자" | 블로그 상단에 이미 있음 — 중복 |
| 설명 | "실제 평점·동선 데이터로…" | 글을 다 읽은 사람에겐 불필요 |
| 패딩 | 32px | 화면 한 칸을 통째로 차지 |
| 버튼 | 흰 배경 큰 버튼 | 광고처럼 보임 |

**글을 끝까지 읽은 사람은 이미 관심이 있습니다.** 설득이 아니라
**다음 행동 한 줄**만 있으면 됩니다.

## 3. 변경안

```html
<div class="tradule-cta">
  <a href="{appUrl}">이 코스를 지도에서 보기 →</a>
</div>
```

```css
.tradule-cta {
  background: #f8fafc;
  border-left: 4px solid #2563eb;
  border-radius: 0 8px 8px 0;
  padding: 14px 18px;
  margin: 28px 0;
  font-size: 15px;
}
.tradule-cta a { color: #1e40af; font-weight: 600; text-decoration: none; }
```

```
· 제목·설명 줄 삭제
· 패딩 32px → 14px
· 배경 그라데이션 → 연회색 + 왼쪽 세로선
· 버튼 → 텍스트 링크
```

**본문 중간 CTA(`midBodyCta`)와 같은 모양**입니다. 이미 그 스타일이 있으니
푸터도 같은 걸 쓰면 글 전체가 일관됩니다.

## 5. ★ 트레쥴 링크는 잠시 빼는 것도 방법입니다

**트레쥴 쪽에 계획 덮어쓰기 버그가 재발했습니다.**
블로그 CTA(`course-open`)를 누르면 보던 계획이 덮어써질 수 있습니다.

```
트레쥴 수정 전까지 CTA 링크를 빼거나,
appUrl 을 /planner 대신 /discover?region={지역} 로 돌리는 것을 검토
```

**제가 트레쥴 수정 완료를 알려드리겠습니다.** 그 전까지는 링크를 누른 독자가
(로그인 상태라면) 자기 계획을 잃을 수 있습니다.

> 비로그인 독자는 저장할 계획이 없어 영향이 없습니다.
> 다만 지금 블로그 독자 대부분이 비로그인이라 실제 피해 규모는 작을 것으로 봅니다.
