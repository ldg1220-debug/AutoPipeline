## 3. ★★★ 판별자는 지역명이 아니라 평점입니다

같은 방식으로 전라를 봤습니다.

```
쿠팡 전라광주2,5센터 카페   ★없음 (0)
전라맛집                   ★없음 (0)
전라우수영                 ★없음 (0)
왓커피 전라감영점           ★없음 (0)
남악저수지                 ★없음 (0)
```

**전라는 5곳 전부 평점이 없습니다. 경주의 진짜 명소는 전부 평점이 있습니다.**

```
지역명 포함 + 평점 있음   →  정당한 장소   (경주 황리단길 · 테라로사 경주점)
지역명 포함 + 평점 없음   →  노이즈        (전라맛집 · 경주원조콩국)
```

### 그래서 규칙을 하나로 줄이세요

```
filterNoisySpots() 를 지우고,  평점 없는 스팟을 제외하세요.
  (sanitizeSpots() 이후 rating 이 null 인 것)
```

지역명 조건이 아예 필요 없습니다.

```
경주  9곳  →  평점 없는 3곳 제외  →  6곳  ✅ 통과
전라  5곳  →  평점 없는 5곳 제외  →  0곳  ✅ 스킵
```

**같은 결과인데 규칙이 하나이고, 지명이 들어간 명소를 안 죽입니다.**

## 4. ★★ MIN_SPOTS 6 은 경계가 위험합니다

```
경주 = 정확히 6곳
```

그리고 course-brief 는 호출할 때마다 곳수가 달라집니다.

```
오늘 낮   경주 12곳
오늘 저녁 경주  9곳   →  필터 후 6곳
```

**6 이 하한인데 결과가 6이면, 다음 호출에서 5가 되어 스킵됩니다.**
같은 키워드가 어떤 날은 되고 어떤 날은 안 됩니다.

```
MIN_SPOTS 를 5 로 내리거나,
스팟이 부족하면 days 를 하나 줄여 재시도하세요  (2박3일 → 1박2일)
```

**재시도 쪽이 낫습니다.** 하루 줄이면 하루당 스팟 밀도가 올라갑니다.
