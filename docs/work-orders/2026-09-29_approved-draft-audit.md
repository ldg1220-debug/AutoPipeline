## 처리 결과 (2026-09-29)

- §4(최우선): `buildTripDataFactsBlock()`을 일차별 그룹화 + "스팟A → 스팟B :
  수단 N분" 구간 쌍 표기로 재작성 — 방향 혼동 자체를 없앰.
- §3(게이트②): "시간대별 동선"류 섹션을 LLM 호출 없이 `buildDeterministicItinerary()`
  (trip_data로 코드가 직접 생성)로 대체 — 날조가 구조적으로 불가능해짐.
  실측 스팟 데이터로 재현 테스트 완료, 트레쥴 기준 데이터와 1:1 일치 확인
  (도교 사원 3일차·Cabana 2일차 정확히 배정).
  `stripWrongDayMentions()` 신규 — 나머지 섹션·**FAQ**에서 "N일차+스팟명"
  조합이 실제 일차와 다르면 문장 삭제(§3③, FAQ 포함 요청 반영).
  `stripTimeOfDayMentions()` 신규 — "오전 9시" 등 데이터에 없는 시각 표현
  문장 삭제(§3④).
- §6①: FAQ 항목도 outline 단계에서 `FORBIDDEN_SECTION_PATTERN`으로 필터링

- §5: `filterUnratedSpots()`에 자연 명소 예외(`해변|beach|island|섬|폭포|
  waterfall|공원|park`) 추가 — 평점 없어도 유지, 본문엔 평점 숫자가 애초에
  안 넘어가므로 지어낼 데이터가 없음.
- §7: 제목이 키워드+10자 미만으로 빈약해지면 trip_data 기반으로 재작성

- §6③(지시어로 시작하는 문단 삭제)·§6④(이동수단 게이트가 본문도 재생성)·
