# 작업 지시서 — 코스 글 모바일 재검토·개선 + 발행 후 화면 점검 도구

작성: 2026-11-26 · 대상: **AutoPipeline** · 요청: 동근님 "필요한 도구 설치해서 블로그 내용·양식·배치 전면 재검토해서 개선"

## 판단
- 디자인 스킬(taste-skill·hallmark·anthropics/skills 의 frontend 계열)은 홈페이지 제작용이라 티스토리 본문(스킨 안 HTML 조각)에는 맞지 않음 → 설치 대신
  Playwright 로 휴대폰 화면(390px)을 실제로 렌더해 보며 고치는 방식(= webapp-testing 방식)을 택함.

## 할 것
```
① 시간표: 5열 표 → 일차별 카드 목록(시간대 칩 · 장소 · 핵심 포인트 · → 이동) — 390px 에서 줄바꿈 깨짐 해결
② 목차: 밑줄 파란 링크 → 칩 버튼
③ 식사·카페 줄: 앞 장소에서 오는 이동을 합치고 앞 장소의 "→ 다음" 줄 생략(같은 이름 중복 제거)
④ 사진 캡션: "Unknown author Unknown author" → "작성자 미상", 반복 구절 제거
⑤ 쿠팡 줄 "준비물 — 준비물 —" 중복 제거, 근거 템플릿의 태그 1개짜리 해시태그 블록 제거
⑥ 비 오는 날 후보: 실내가 분명한 박물관·수족관·미술관만 (전망대·시장 제외)
⑦ 핵심 포인트(요약 구절)도 사실 검증 — "현존 최고령 천문대" 같은 근거 밖 최상급 차단
⑧ 일차 소개 군더더기 "모두 N곳이고, 아래 장소 순서대로 이동합니다" → "(N곳)"
⑨ 도구: scripts/audit-post.js + 메뉴 13 "발행 글 휴대폰 화면 점검" + npm run audit
   (가로 넘침 · 깨진 이미지 · 사진 수 · 광고 슬롯 높이 · 넓은 표 · 첫 화면 본문 · 반복 문장, 화면 PNG 저장)
```
