## 1. ★★★ API 계약 변경 (트레쥴 #298)

```
distanceSource   "route" | "straight" | "mixed"(신규)
spots[i].toNextSource   "route" | "straight"   (그날 마지막 스팟엔 없음)
spots[i].toNextFallback "driving"              (짝 지시서 배포 후 — transit 실패를 차량으로 대체한 구간)
```

실측: 이제 오사카 · 도쿄 · 나고야도 **route** 입니다(어제는 straight 라 글에서 이동 분이 전부 빠졌음).

## 2. 고칠 것

```
① "straight 코스면 분 전부 삭제" → 구간 단위로
   toNextSource === "route"     → 분 표기
   toNextSource === "straight"  → 분 생략 ("직선거리 기준" 표기) — 배 구간은 기존 "배편 (시간 미확인)" 유지
   distanceSource 가 mixed 여도 route 구간은 살림
   (distanceSource !== "route" 를 straight 로 보는 코드가 있으면 제거)
② toNextFallback === "driving" 구간 표기: "차량 기준 N분"
   일자 카드 표 "다음 이동" = "차량 기준 N분" · 포인트 문장에서 "대중교통" 언급 금지
   개요 · 한 줄 정리에서도 같은 표기
③ 직선거리 표기("장소 간 직선거리 기준")는 distanceSource === "straight" 일 때만
④ 코스 한눈에 보기 "수단은 차량 N구간 …" 집계에 폴백 구간은 "차량(기준)" 으로 따로
```
