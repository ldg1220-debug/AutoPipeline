## 2. ★★★ 반려의 공통 원인 — 게이트가 지우고, QA 가 짧다고 떨어뜨립니다

세 편의 반려 사유가 거의 같습니다.

```
섹션 글자 수 미달: [1일차 일정, 2일차 일정, 3일차 일정, 시간대별 동선] (최소 350자)
구체 수치 부족: [시간대별 동선]
시간대별 동선 섹션이 비어 있음                         (경주)
H2/H3 태그가 사용되지 않음                             (세 편 모두, 매번)
글 전체 분량 부족: 3194 / 2953 / 2368자 (최소 4000자)    (재작성 후)
```

그리고 **재작성할수록 짧아집니다.**

```
세부 2박3일   4080자 → 재작성 2221자
경주 2박3일   3243자 → 재작성 1662자
세부 5박7일   3784자 → 재작성 1345자
```

### 원인 셋

```
① 일자 섹션은 코드가 만든 "장소 → 장소" 목록뿐이라 짧음 → QA 가 350자 미달로 반려
   (9/29 지시서 §3② 는 "목록 + 그날 스팟만 넣은 해설 2~4문장" 이었습니다 — 해설이 빠졌습니다)
② 아웃라인이 "시간대별 동선" 섹션을 또 만들고, 게이트(시각·일차 불일치)가 그 문장을 지워 섹션이 비거나 짧아짐
③ 재작성은 글 전체를 다시 쓰고 게이트가 또 지우니 매번 더 짧아짐
```

### 고칠 것

```
① 일자 섹션 = 코드 목록 + 그날 스팟만 넣어 생성한 해설 2~4문장
   (다른 날 스팟 언급 금지 · 과거형 금지 · 생성 후 게이트 통과)

② 일자 섹션을 만들었으면 아웃라인의 "시간대별 동선 / 이동 방법 / 동선 및 소요시간" 류는 제거
   (같은 내용을 LLM 이 한 번 더 쓰면서 틀리고, 게이트가 비웁니다)

③ QA 규칙
   · 코드가 만든 블록(일자 목록 · 요약 · 타임라인 표)은 섹션 글자수·수치 규칙 면제
   · "H2/H3 태그 없음" 은 오탐입니다 — 섹션은 heading 필드로 렌더됩니다.
     QA 에 ## 헤딩을 붙인 렌더본을 넘기거나 이 항목을 빼세요
   · 전체 최소 4000자 → 3000자 (표·목록 텍스트 포함해 계산)
     사실만 쓰게 해놓고 4000자를 채우라고 하면 다시 지어냅니다

④ 재작성
   · 글 전체가 아니라 반려 사유에 걸린 섹션만 재생성
   · 재작성 결과가 1차보다 짧으면 1차 초안을 유지
```

## 3. ★★★ 구간이 계속 틀리던 진짜 원인 — 평점 없는 스팟을 빼면 구간 사슬이 끊깁니다

트레쥴 경주 3일입니다.

```
d1  경주 황리단길 →도보 8→ 대구갈비 본점(평점 없음) →도보 6→ 경주성동시장 →차량 8→ 테라로사 경주점
d2  경주월드 →도보 10→ 경주보문관광단지 →차량 7→ 야드
d3  점심밥상저녁술상 →차량 12→ 경주중앙시장(평점 없음) →차량 18→ 경주 용황 …(평점 없음)
```

AutoPipeline 은 평점 없는 세 곳을 빼고 **7곳**으로 만듭니다. 그러면 이렇게 됩니다.

```
황리단길 의 "다음 8분" 은 원래 → 대구갈비
대구갈비를 빼면  → "황리단길 → 경주성동시장 : 도보 8분"   ← 트레쥴에 없는 구간
점심밥상 의 "다음 12분" 은 원래 → 경주중앙시장
중앙시장을 빼면  → 가리킬 곳 없는 "12분"                  ← Pass 5 가 "API 에 없다" 고 지적
```

**지난 세부 초안의 "House of Lechon 까지 차로 40분" 도 같은 원인입니다** — Lechon 다음의 해변(평점 없음)을 뺐을 때 40분이 허공에 떴습니다.

**LLM 이 틀린 게 아니라, 우리가 넘긴 구간 데이터가 틀렸습니다.**

### 고칠 것

```
경로(일정 목록 · 구간 · 요약 줄 · 타임라인 표)는 트레쥴 스팟 전부로 만드세요.
평점 없는 스팟은
  · 경로에는 그대로 둠 ("대구갈비 본점 — 평점 정보 없음")
  · 평점 인용 · "추천" 서술 · 제목 · 정보카드에서만 제외
생존성 판정(평점 있는 스팟 ≥ 6)은 지금처럼 유지
```

### 게이트⑥ — 분이 틀린 문장

```
Pass 5 가 잡은 것: "경주월드 → 보문관광단지 차량 7분"  (트레쥴: 도보 10분)
```

지금 코드는 **"분 → 수단" 표로 수단만** 고칩니다. 7분은 다른 구간(보문→야드)에 있으니 그대로 통과했습니다.
9/28 지시서 §3 대로 **출발·도착 스팟명까지 대조**해서, 분이 다르면 문장을 지우세요.
