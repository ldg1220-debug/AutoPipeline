# 블로그 전면 검토 — 구성 · 시인성 · 광고 · 사진 · 에셋 (2026-11-22)

대상: maeilg.com 최신 발행글 291(청주 1박2일)·288(나고야 3박4일), 모바일 390px 실측(Playwright) + 비교 글(트립스토어 오사카 2박3일, 트래비 오사카 2박3일) + Google 공식 가이드.

## 0. 한 줄 결론

지금 발행되는 글은 **"같은 사실을 5번 반복하는 데이터 표 + 지도 3장"**이고, 사진이 0장, 첫 화면은 네이버 지도 광고가 차지하며, 애드센스 슬롯은 렌더 높이 0입니다. 이미 만든 새 템플릿(D-166~171, 장소 설명·Commons 사진·시간대 표·FAQ 5)이 **운영에 켜져 있지 않습니다**(`COURSE_GROUNDED_DESC` 미설정 — 291이 구 템플릿). 1순위는 새 템플릿을 켜는 것입니다.

## 2. 문제와 권고 (우선순위순)

### P0 — 바로 할 것

1. **새 템플릿 켜기**: `.env`에 `COURSE_GROUNDED_DESC=on`. 지금 운영 글은 구 템플릿이라 지금까지 고친 장소 설명·사진·시간대 표·상황별·FAQ 5가 독자에게 전혀 안 보입니다. 단, 켜기 전에 동근님 PC에서 LLM 실행 샘플 1편(`_stage2_llm2`)으로 D-171 오류(불국사·해유관·추억의달동네·첨성대) 해소를 확인.
2. **애드센스 슬롯 0px 확인**: 3개 모두 높이 0. 헤드리스 환경에서는 원래 채워지지 않을 수 있으니, 실제 휴대폰에서 광고가 보이는지 동근님이 확인. 안 보이면 애드센스 계정 상태(사이트 승인·정책 위반 알림)부터 확인. `ads.txt`는 정상(pub-8293919069319745).
3. **블로그 소개 문구에서 "평점" 삭제** (티스토리 관리 > 블로그 설정). 예: "실제 좌표로 계산한 동선과 지도로 여행 코스를 소개합니다".

### P1 — 구성·시인성

4. **반복 제거**: 291 한 편에 같은 사실이 "리드 → 한눈에 보기 박스 → 코스 개요 → 코스 한눈에 보기 → 종류별 장소 → 일자 표 → 이 날의 포인트 → 동선 요약 → 장소별 한 줄 정리 → FAQ"로 반복됩니다(총 이동 42.2km는 4번, 하루별 km는 3번). 새 템플릿은 이 반복을 대부분 없앴습니다. 구 템플릿을 계속 쓴다면 "코스 한눈에 보기"·"장소별 한 줄 정리" 두 섹션 삭제.
5. **한눈에 보기 박스 대비**: 갈색~주황 그라데이션 위에 짙은 파랑 글씨라 모바일에서 읽기 어렵습니다. 흰 배경 + 왼쪽 색 띠(인용 박스형)로 바꾸고, 경로 화살표 나열(8곳 →…)은 3곳만 보이고 "외 5곳"으로 접기.
6. **첫 화면 문장**: 리드가 "…이동 합계 약 1.6시간." 한 문장뿐이라 og:description·검색 스니펫이 숫자 나열이 됩니다. 새 템플릿의 3문장 리드(코스 논리 · 누구에게 · 이 글에서 볼 것)가 이 문제를 해결합니다. 추가로 `<meta name="description">`을 티스토리 요약 입력란에 직접 넣도록 발행기에서 지정(지금은 티스토리가 본문을 잘라 씀).
7. **섹션 번호 배지(1~6)**: 읽는 데 도움 없이 세로 공간만 씀 → 새 템플릿에서는 H2만 두고 배지 제거 권장.

### P1 — 사진·에셋

8. **장소 사진 0장 → 3~6장**: 비교 글은 10~22장. 새 템플릿의 Commons 사진(장소당 1장, 글당 최대 6장, 작성자·라이선스 캡션)이 이 공백을 메웁니다. 지도 3장 + 사진 4~6장이 적정선.
9. **지도 이미지 크기**: 모바일에서 높이 184px(가로형)라 마커·지명이 읽히지 않습니다. 트레쥴에 모바일용 세로/정사각(예: 800×800) 지도 요청하거나, 일자 지도는 "탭하면 크게 보기" 링크로.
10. **썸네일 일관성**: "이 블로그 인기글"에서 DALL·E 일러스트(같은 '모자 쓴 여성 뒷모습' 반복), 지도+작은 글씨, 검은 배경 플레이스홀더(평창 289 — 생성 실패로 보임)가 섞여 있습니다. 기본값을 `map`으로 바꿨으니(D-166) 이후 글은 지도 썸네일로 통일되지만, 지도 위 제목 글씨가 작아 목록에서 안 읽힙니다 → 제목 글자 크기 2배·2줄 이내·지역명 크게. 실패 시 검은 화면 대신 Commons 대표 사진으로 대체.
11. **인포카드**: 티스토리가 data: 이미지를 지원하지 않아 매번 제거됩니다(로그 "data: URI 이미지 블록(인포카드) 제거"). 생성 비용·시간만 들고 독자에게 안 보입니다 → 업로드 경로로 바꾸거나 생성 중단.
12. **경제 글 잔존**: 인기글에 "인플레이션 대처법", "노후준비지원법"이 섞여 여행 블로그 주제 일관성을 흐립니다 → 비공개 전환 또는 별도 카테고리로 숨김(삭제는 동근님 판단).

### P2 — 광고 배치

13. **권장 배치(모바일)**: Google은 첫 화면에 읽을 내용이 충분하면 상단 광고가 정책상 문제없다고 하고, 모바일 상단에는 320×100, 큰 300×250은 첫 화면 아래를 권장합니다. 지금 첫 화면은 스킨의 네이버 지도 광고 2개가 이미 차지 → 애드센스 상단 슬롯은 **리드 3문장 + 시간표 다음**(약 1.5화면 아래)으로.
   - 권장 3곳: ① 시간표 바로 아래 ② 2일차 시작 전(일차 사이) ③ FAQ 앞. 장소 H3 사이·사진 바로 옆·CTA 버튼 옆은 피하기(오클릭 정책).
   - 스킨의 네이버 지도 광고(첫 화면)는 애드센스와 경쟁 + 첫 화면 콘텐츠를 밀어냄 → 티스토리 스킨 광고 설정에서 본문 상단 위치 끄기를 검토.
14. **제휴 링크 밀도**: 291은 쿠팡·Klook·eSIM 링크가 본문·하단에 흩어져 있고 고지문이 2번 나옵니다. 새 템플릿은 상단 고지 1회(D-171). 제휴 블록은 "떠나기 전 체크리스트" 한 곳으로 모으기 권장.

### P2 — 신뢰·검색

15. **직접 경험이 없는 글의 한계**: Google 가이드는 직접 가 본 경험·자체 사진을 품질 신호로 봅니다. 우리는 경험담을 지어내지 않는 대신 ① 실제 좌표 기반 동선 ② 출처 있는 장소 설명 ③ 출처 표기 사진 ④ "트레쥴에서 내 일정 저장"으로 차별화 — 이 방향 유지. 글 끝 "이 글은 이렇게 만들었습니다"(데이터 출처·작성 방식) 한 단락 추가 권장.
16. **제목**: "…일정 짜기 — 나고야 성 들르는 19곳", "…코스 정리 · 이동시간까지 본 8곳"처럼 템플릿 5종이 섞여 블로그 목록이 들쭉날쭉. 새 템플릿 제목("{지역} {N박M일} 코스 | {권역} 동선 + 시간표") 하나로 통일 권장.

## 4. 바로 실행 순서

1. 동근님: 휴대폰으로 291에서 애드센스가 보이는지 확인, 블로그 소개 문구에서 "평점" 삭제, 스킨 상단 네이버 지도 광고 끄기 검토.
2. 동근님 PC: `COURSE_GROUNDED_DESC=on`으로 메뉴 3 샘플 1편 확인 → 문제없으면 운영에 켜기.
3. 세션(다음 지시서로): 광고 슬롯 위치 이동(시간표 아래·일차 사이·FAQ 앞), 섹션 번호 배지 제거, 썸네일 제목 크기·실패 대체, 인포카드 중단, 제목 템플릿 통일, 메타 설명 직접 지정.
4. 트레쥴: 모바일용 지도 비율(정사각) 제공.
