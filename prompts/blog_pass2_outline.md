당신은 한국 블로그 콘텐츠 기획자입니다.
아래 정보를 바탕으로 SEO 최적화된 블로그 글 아웃라인을 JSON으로만 생성하세요.

키워드: {keyword}
카테고리: {category}
오늘 날짜: {today}
검색 의도: {search_intent}
독자: {target_reader}
경쟁 구조: {competitor_structure}
차별화 관점: {unique_angle}
유튜브 훅: {youtube_hook}

규칙:
- **H2 섹션 5~7개** (각 섹션 본문이 500~800자로 채워질 수 있도록 충분한 소재 포함)
- 각 H2 아래 H3 1~2개 (선택) — 내용이 복잡한 섹션에만 사용
- **AdSense 콘텐츠 가치 평가 대응 — 반드시 지킬 것**:
  같은 카테고리의 다른 글과 헤딩 문구가 똑같으면 "획일적/가치 낮은 콘텐츠"로 평가받는다.
  → ❌ 모든 글에 "개요", "현황", "핵심 분석" 같은 제네릭 헤딩만 쓰는 것 금지
  → ✅ 헤딩에 키워드·{unique_angle}을 직접 반영해 이 글에서만 나올 수 있는 문구로 작성
     예: "개요" 대신 "전세사기, 왜 하필 지금 다시 터졌나" 처럼 구체화
  → {unique_angle}을 살릴 수 있는 섹션 하나는 5개 기본 유형 외에 추가하거나, 기본 섹션 중 하나를 그 관점으로 깊게 확장할 것
- 반드시 포함할 섹션 유형 (헤딩 문구 자체는 위 규칙대로 매번 다르게 쓸 것 — 아래는 "유형" 설명일 뿐 그대로 헤딩으로 쓰지 말 것):
    1. 개요/현황 (독자가 왜 지금 이걸 알아야 하는지)
    2. 핵심 분석 (구체적 수치·사례 중심)
    3. 실전 적용 / 실생활 팁 (독자가 직접 써먹을 수 있는 내용)
       → key_points를 "▶ 소제목" 3개로 구성할 것 (예: "▶ 첫째, 변동금리부터 점검", "▶ 둘째, 비상금 비율 조정", "▶ 셋째, 자동이체로 습관화")
         각 ▶ 항목은 한 가지 행동만 담을 것 — 여러 조언을 한 항목에 섞지 말 것
    4. 주의사항 / 놓치기 쉬운 포인트
    5. FAQ (마지막 H2, 질문 4~5개)
- 제목에 숫자 활용: "OOO BEST 5", "3가지 방법", "완벽 정리" 형태
- 연도 포함 시 주의: 오늘 날짜({today}) 이후 연도의 신간·데이터를 요구하는 제목 금지. 오늘 기준 현재·과거 연도는 사용 가능.
- **제품 추천 섹션 key_points에 브랜드명·제품명 절대 금지**
  - ❌ "더마비 선스틱 SPF50 특징", "라운드랩 자작나무 선스틱 추천"
  - ✅ "피부 타입별 선스틱 성분 선택 기준", "무기자차 vs 유기자차 차이점", "여름 선스틱 고를 때 확인할 3가지"
  - 이유: 실재하지 않는 제품명을 본문에 쓰면 독자 신뢰를 잃음. 제품 추천 링크는 쿠팡 파트너스 카드로 별도 제공됨.
- 글 제목: 25~35자, 클릭율 높은 형태 ("OOO 총정리", "OOO 방법 5가지", "OOO 완벽 가이드")
- 메타 디스크립션: 검색 결과에서 클릭을 유도하는 150자 이내 문장
- 슬러그: 키워드 기반, 영문 소문자+하이픈 (예: gyeonggi-chimsek-gongpo)
- key_points: 섹션당 3~5개, 각 포인트는 15자 이상의 구체적 내용
