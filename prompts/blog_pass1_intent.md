당신은 한국 SEO 전문가입니다. 아래 키워드로 검색하는 사람의 의도를 분석하고,
상위 노출 블로그 글이 어떤 구조로 되어 있는지 파악해 JSON으로만 응답하세요.

키워드: {keyword}
카테고리: {category}
오늘 날짜: {today}

분석 항목:
1. search_intent: "informational" | "commercial" | "navigational" 중 하나
2. target_reader: 이 글을 읽을 독자 페르소나 (1~2문장, 추상적 "일반 독자" 금지 — 구체적 상황 묘사 필수)
   예: "아파트 청약을 처음 준비하는 30대 직장인으로, 1순위 자격이 되는지 확인하고 싶어하는 사람"
3. competitor_structure: 상위 노출 글들이 공통으로 다루는 섹션 주제 5~7개 (배열)
4. unique_angle: 경쟁 글과 차별화할 수 있는 구체적 관점 1가지
   **【중요】** "더 쉽게 설명한다", "종합적으로 다룬다" 같은 막연한 차별화는 금지.
   반드시 아래 유형 중 하나로 구체화할 것:
   - 특정 독자 상황에 집중: "맞벌이 신혼부부가 청약 1순위 요건을 충족하는 방법"
   - 최신 변경사항 반영: "2026년 개정된 기준으로 다시 보는 OOO"
   - 실패 사례·함정 중심: "OOO 신청했다가 탈락한 이유 3가지"
   - 비교·선택 가이드: "A와 B 중 내 상황에 맞는 것 고르는 기준"
   - 숫자·절차 중심: "OOO 신청 전 반드시 확인할 체크포인트 5가지"
5. affiliate_category: 이 키워드와 연관성 높은 쿠팡 상품 카테고리 (없으면 null)
6. specificity_score: 이 키워드가 얼마나 구체적인지 1~5 점수
   1 = "글로벌 공급망 변화"처럼 대형 언론이 이미 포화 상태로 다루는 광범위 주제 (개인 블로그가 추가 가치 내기 어려움)
   5 = "2026년 7월 역세권 장기전세주택 신청 자격 조건"처럼 검색자가 실제 행동을 위해 찾는 초구체적 주제
   → 점수 2 이하면 unique_angle에서 더 좁은 각도로 반드시 재설정할 것

JSON만 응답:
{
  "search_intent": "informational",
  "target_reader": "",
  "competitor_structure": [],
  "unique_angle": "",
  "affiliate_category": null,
  "specificity_score": 3
}
