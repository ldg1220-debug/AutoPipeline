# 티스토리 제품 리스티클 스타일 가이드 (쿠팡 파트너스형)

> 참고 자료: tistory_style_1.txt, tistory_style_3.txt
> 기존 blog_pass1~3 (경제/시사 정보형 글)과는 완전히 다른 글 유형이다.
> 어떤 카테고리/조건에서 이 스타일을 쓸지는 아직 결정되지 않았으므로,
> 아래 가이드는 "참고용 스타일 정의"이며 현재 파이프라인 어디에도 자동 연결되어 있지 않다.
> (추후 product-listicle 전용 콘텐츠 타입을 만들 때 이 문서를 prompt로 그대로 주입하면 된다.)

## 구조

1. **계절/상황 공감 도입부**
   - "날씨가/기온이 ~해지는 N월이 되면" 식의 시즌 멘트로 시작
   - 일상 속 짜증/불편 3가지를 구체적 장면으로 묘사 (예: 대중교통 옆자리 시선, 무거운 드라이기, 좁은 틈새 청소)
   - "~할 순 없을까?" 형태의 인용형 반어 질문으로 도입부 마무리

2. **전환 멘트**
   - "OO를 똑똑하게 하는 사람들은 절대 몸 고생을 하지 않습니다" 류의 한 줄로
     도입부(문제) → 본문(해결책 3종) 전환
   - 이어서 3개 제품을 한 문장씩 요약 나열 (콜론 구조: "~를 고르고, ~를 배정하며, ~로 ~를 이뤄내죠")

3. **제품 3개 (고정 포맷, 각 제품마다 동일하게 반복)**
   - `N. 제품명` H2/H3 헤딩
   - 제품명을 alt 텍스트로 쓰는 이미지 placeholder 2~3회 반복 (실제로는 이미지가 들어갈 자리)
   - **굵게 처리된 한 줄 후킹 문구** — 이상적 사용 시나리오를 인용문처럼 묘사
   - 타겟 독자 한 줄 (예: "~때문에 스트레스받던 분들을 위한 인생 정착템입니다")
   - 기능 설명 정확히 3개, 각각 "**굵은 기능명**: 설명" 형태, 과장되고 혜택 중심의 어조
   - 마무리 인용형 문단 (이탤릭/인용 톤) — 클릭 유도로 자연스럽게 연결
   - CTA 라인: `👆 [클릭 유도 문구] 제품명 최저가/혜택/재고 보기`

4. **마무리 통합 문단**
   - "매일 반복되는 OO의 피로도를 결정하는 것은 ~가 아니라 ~에 있습니다" 구조의 통찰형 문장
   - 3개 제품을 한 문단에 다시 호명하며 테마로 묶기
   - 마지막 문장은 행동 유도형 종결 ("오늘 소개해 드린 ~와 함께 ~를 만끽해 보세요!")

## 어조/문체 특징

- 1인칭 화자 없음 (Naver 스타일과 달리 "아빠/저" 같은 personal voice 미사용)
- 전형적인 카피라이팅 톤: 과장된 형용사, 반복되는 "~혁명", "~치트키", "~완벽 해방" 표현
- 모든 제품 설명은 benefit-first (기능 자체보다 "이게 왜 좋은지"를 먼저 말함)
- 문단 사이 공백 라인(`​`)을 자주 사용해 시각적으로 호흡을 줌

## 적용 시 주의

- 기존 정보형 글(blog_pass1_intent → blog_pass2_outline → blog_pass3_body)과 혼용하지 말 것.
  이 스타일은 "정보 전달"이 아니라 "제품 추천/구매 유도"가 목적이므로 글 전체 구조가 다르다.
- 실제로 파이프라인에 연결하려면 다음을 먼저 결정해야 한다:
  1. 어느 카테고리(예: 생활/리빙/뷰티)에서만 쓸지, 아니면 전용 콘텐츠 타입으로 분리할지
  2. 제품 3개를 어디서 가져올지 — `monetizer.js`의 `searchCoupangProducts()` 결과를 그대로 매핑할 수 있는지
  3. 기존 QA 기준("최소 4개 섹션" 등)이 이 포맷(3개 제품 + 도입/마무리)에도 그대로 적용되는지 재검토 필요
