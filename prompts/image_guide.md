# 이미지 가이드 (blog_asset_builder.js)

> 이 문서는 블로그 이미지 생성(썸네일·인포카드)의 규칙을 정의한다.
> `blog_asset_builder.js`는 이 파일을 읽어 LLM 프롬프트에 주입한다.
> **아래 규칙은 모두 "반드시 따를 것" — 위반 시 결과물 재생성 대상이다.**

## 1. 헤드라인 텍스트 (HTML/CSS 썸네일용)

- 반드시 14자 이내로 작성할 것 (800×450 캔버스에서 잘리지 않는 최대 길이)
- 반드시 숫자 또는 구체적 사실을 포함할 것 (예: "전세가 7% 하락", "금리 3.5% 시대")
- 반드시 한 줄 또는 두 줄로 자연스럽게 끊어지는 구문으로 작성할 것 — 단어 중간에서 줄바꿈되는 표현 금지
- 자기소개·채널명·"안녕하세요" 등 도입 멘트 절대 금지

## 2. 인포카드 핵심 수치 (extractKeyStats)

- 반드시 본문에 실제로 등장한 수치만 사용할 것 — 추측/창작 금지
- value는 반드시 8자 이내로 압축할 것 (카드 레이아웃 고정폭 기준)
- label은 반드시 10자 이내로 압축할 것
- 숫자가 전혀 없는 섹션은 반드시 핵심 팩트 한 줄로 대체할 것 (빈 카드 금지)

## 3. 레이아웃/디자인 규칙

- 카테고리별 고정 색상(`CARD_COLORS`)을 반드시 유지해 채널 시각 아이덴티티를 보존할 것
- 텍스트는 반드시 배경과 명도 대비 4.5:1 이상이 되도록 밝은 텍스트 + 어두운 배경 조합을 사용할 것
- 한 화면에 들어가는 텍스트 블록은 반드시 캔버스 폭의 90% 이내에서 줄바꿈되도록 padding을 둘 것

## 4. 자가 검수 체크리스트 (Vision self-review)

생성된 이미지는 반드시 아래 항목을 통과해야 최종 자산으로 채택된다:

1. 텍스트가 캔버스 밖으로 잘리거나 겹치지 않는가
2. 텍스트와 배경의 대비가 충분해 읽기 쉬운가
3. 빈 공간이 과도하게 남아 레이아웃이 비어 보이지 않는가
4. 카테고리 색상 가이드를 따르고 있는가

하나라도 FAIL이면 최대 2회까지 폰트 크기·줄바꿈을 조정해 재생성한다.
2회 재시도 후에도 실패하면 Pexels 폴백으로 전환한다.
